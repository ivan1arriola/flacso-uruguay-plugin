# Campana de consultas

Mautic debe tener una campana publicada llamada `Consulta academica`. WordPress conoce solo su ID configurado y agrega contactos tras una sincronizacion exitosa.

La primera version contiene un email inicial aprobado y puede bifurcar por `flacso_cohorte_estado`. No contiene esperas, seguimientos ni eventos diferidos. La campana de prueba existente no se reutiliza.

La aceptacion de la API confirma sincronizacion y membership; no confirma entrega de correo.
